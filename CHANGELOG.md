# Changelog

## 1.1.0 — 2026-11-26

- Added object-sheet analysis for multiple views of the same object.
- Added explicit appearance/motion bindings and in-place proxy replacement for Video guides.
- Made declared guide openings authoritative; recognized duplicate openings are rejected.
- Documented use of **Stage output from version 0.9.0 onward**: MP4 plus the
  `_compiler.txt` export, with manual mappings and paste into the guide field.
  No automatic MP4/TXT/JSON importer is included.
- Clarified Ollama/OpenAI prerequisites in English and Italian launch guides.
- Preserved saved prompts, manual versions, snapshots, media and earlier releases.

See [release notes](docs/RELEASE-1.1.0-EN.md), [Stage usage](docs/STAGE-EN.md)
and [Italian changelog](CHANGELOG-IT.md).

## 1.0.0 — 2026-11-22

First numbered stable release: persistent Discard, unified character-sheet
descriptions, one Analyze action and shared descriptions in compatible scene drafts.
