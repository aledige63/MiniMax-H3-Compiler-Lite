REQUIREMENTS
Windows 11 x64 and Python 3.12 x64 with pip and the py launcher:
https://www.python.org/downloads/windows/
AI features require local/remote Ollama with installed models, or an OpenAI API
key. Configure and verify text and vision in User settings; one multimodal model
can serve both roles. OpenAI requests may incur API charges. Python, Ollama,
models and keys are not included. No models are downloaded automatically.

STARTUP
Extract the entire ZIP into a new writable local folder outside synchronized
storage. Run Avvia.cmd. First launch requires Internet for requirements.lock
installation and an existing Python 3.12 installation. Keep the window open;
save edits and wait for jobs to finish before stopping with Ctrl+C.
Local URL: http://127.0.0.1:8767/

UPGRADING AND DATA
Save edits, stop the old server and create a verified backup first. Preserve
the data archive or exact --data-dir path. Do not overwrite the old code folder.
Default archive: %LOCALAPPDATA%\MiniMax H3 Compiler Lite\data
Saved prompts, versions, snapshots and files are preserved. New instructions
apply only to fresh analyses and compilations.

CHANGES AND STAGE
Object sheets and explicit Video bindings, with a consistent declared opening.
Use MP4 and Prompt for MiniMax Compiler (_compiler.txt) output from Stage 0.9.0:
add the Video, map its figures to Subjects and paste only the narrative in the
English guide field, up to 2500 characters. Also connect the files in H3.
See STAGE-EN.md, OBJECT-SHEET-EN.md, GUIDE-MAPPING-EN.md and RELEASE-1.1.0-EN.md.
No automatic MP4/TXT/JSON importer or H3 execution is included.

Verify SHA256SUMS.txt. Synthetic tests and Mac backend checks passed; a fresh
