# Roadmap / Piano futuro

## English

Future work includes evaluating Stage integration to use its exported guide video
and matching camera prompt directly. Stage is still under development.
Methods, exchange format and timing remain undecided pending a real export trial.
Joint MP4/TXT import and a single exchange package remain options, not agreed designs.
This version does not implement the integration. Linux remains outside the plan.

## Italiano

È prevista la valutazione di un'integrazione con Stage per usare direttamente
il video guida e il relativo prompt camera esportati. Stage è ancora in sviluppo.
Modalità, formato di scambio e tempi restano da definire dopo una prova con un
export reale. Importazione congiunta MP4/TXT e pacchetto unico sono opzioni,
non decisioni implementative. Questa versione non implementa l'integrazione.
Linux resta escluso.
