# Roadmap / Piano futuro

## English

Stage 0.9.0 MP4 and `_compiler.txt` exports can be used manually in Compiler 1.1.0;
see [Stage usage](STAGE-EN.md). Automatic joint MP4/TXT/JSON import remains future
work. No external video generation is executed by Compiler. Linux remains excluded.

## Italiano

Gli export MP4 e `_compiler.txt` di Stage 0.9.0 sono utilizzabili manualmente nel
Compiler 1.1.0: [guida Stage](STAGE-IT.md). L’importazione automatica congiunta
MP4/TXT/JSON resta un lavoro futuro. Il Compiler non esegue generazioni video
esterne. Linux resta escluso.
