# Publication copy scope

Application code, pinned dependencies and launchers are preserved.
Excluded: external reference materials, inventories, internal specifications and
acceptance records, screenshots, inference/benchmark reports and machine metadata.
One regression fixture is derived from synthetic cases; it contains only input hashes,
interpretations and expected text, without models, performance or local metadata.
Addresses and passwords in tests are intentional synthetic values, not real credentials.

The public repository has its own history, beginning with the reviewed source
import. Original development commits, branches, tags, personal email addresses
and local configuration are not imported. Public commits use GitHub noreply
addresses; private development history stays separate.
MIT and copyright aledige are retained. English is the primary README language;
the Italian version is README-IT.md. Operating guides remain available in both.

The standalone recipe and its tests are adapted to work without old tags.
The development version is distinct from tested packages. No old tag moved and no
tested ZIP changed. The source is published at
https://github.com/aledige63/MiniMax-H3-Compiler-Lite.
The tested launch ZIPs are separate distributions; publishing these sources
does not replace them. Download, installation and update instructions are in
[README.md](../README.md).
