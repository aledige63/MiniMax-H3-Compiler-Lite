# Publication copy scope

Application code, pinned dependencies and launchers are preserved.
Excluded: external reference materials, inventories, internal specifications and
acceptance records, screenshots, inference/benchmark reports and machine metadata.
One regression fixture is derived from synthetic cases; it contains only input hashes,
interpretations and expected text, without models, performance or local metadata.
Addresses and passwords in tests are intentional synthetic values, not real credentials.

The new history contains only this reviewed copy, with public author aledige and
conventional address `aledige@users.noreply.github.com`. This does not verify email
association with a GitHub account. Old commits, branches, tags, remotes, email addresses
and local configuration are not imported. Private history stays separate.
MIT and copyright aledige are retained. Operating guides are available in IT/EN.

The standalone recipe and its tests are adapted to work without old tags.
The development version is distinct from tested packages. No old tag moved and no
tested ZIP changed. Publication will still require a destination/visibility, user
authorization and any release notes. This preparation creates no remote or push.
